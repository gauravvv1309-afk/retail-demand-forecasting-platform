# Client Questions

Before development begins, I would ask the client the following questions to better understand the business problem, available data, technical environment, deployment expectations, security requirements, and definition of success.

## 1. Business Questions

1. What is the main business problem you want this forecasting system to solve?

2. Which teams will use the forecasts most often?

3. Which products should be included in the first version of the system?

4. Which stores or locations should be included?

5. How far into the future should the system forecast demand?

6. Should forecasts be generated daily, weekly, monthly, or at another frequency?

7. What decisions will users make based on the forecast?

8. Are there certain products or stores that are more important than others?

## 2. Data Questions

9. What historical sales data is currently available?

10. How many months or years of historical data do you have?

11. What format is the data stored in, for example CSV files, Excel files, or a database?

12. Does the data contain product information such as product ID, category, price, and description?

13. Does the data contain store information such as store ID, location, and region?

14. Do you have information about promotions, discounts, holidays, or special events?

15. Are stock levels or inventory records available?

16. Are there known data quality issues such as missing values, duplicate records, or incorrect dates?

17. How often is new sales data added or updated?

## 3. Technical Questions

18. What systems currently store the sales and inventory data?

19. Is there an existing database or data warehouse that the forecasting system should connect to?

20. Does the company prefer a particular programming language, cloud provider, or technology stack?

21. Does the forecast need to be available through an API, dashboard, application, or file export?

22. Does the system need to connect to any existing business applications?

23. How many users are expected to use the system?

## 4. Deployment Questions

24. Where should the final system be deployed?

25. Should the system run in the cloud, on the company's own servers, or somewhere else?

26. How often should new forecasts be generated?

27. Should model retraining happen automatically or manually?

28. Does the company already have a development, testing, and production environment?

## 5. Security Questions

29. Does the data contain any sensitive or confidential information?

30. Who should be allowed to access the forecasting system?

31. Are there different access levels for different users?

32. Are there any company security policies that the solution must follow?

33. Are there any restrictions on storing or processing the data in the cloud?

34. Should user activity or system activity be logged for auditing purposes?

## 6. Success Criteria Questions

35. How will the company decide whether the forecasting system is successful?

36. Is there a minimum forecasting accuracy that is expected?

37. Is reducing stockouts one of the main measures of success?

38. Is reducing overstocking or excess inventory another measure of success?

39. Is there an existing forecasting process that the new system should be compared against?

40. How quickly should the system produce forecasts after receiving new data?
